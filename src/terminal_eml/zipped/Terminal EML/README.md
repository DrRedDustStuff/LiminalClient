### Quick warning:

The mods are downloaded at your own risk.
Mods will NOT be sandboxed (tested) for viruses or malicious behavior

## How to use:
1. Run the `.exe`.
2. Type `lsmods` to list all *currently* installed mods.
3. Type `menable` to set the state of mod `arg0` to `arg1`, which is either Enabled or Disabled.
4. When you want to update the mods, type `umods` to update the mods.
5. To run the game, type `start`.
