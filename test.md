## Interpose is a **blueprint mod loader** for **unreal engine games**.
This release is setup for Escape the Backrooms.
<br />With it you can *spawn* in your own blueprint mods, and have them nicely congregated within the mod loader menu.
<br />The mod loader comes with some debugging utilities like debug print functions
<br />You can also have your mod, auto populate the mod loader menu with it\'s own submenus, and buttons.
<br />This mod also fixes vr for the 4.0 version of the game.
<br />It also activates the console which you can toggle with the ~ or \` key.
<br />
<br />
<br />To install, download the latest release
<br />then unzip the Interpose.zip so you are left with the Z_Interpose_P.pak
<br />Then go to your Escape the Backrooms game install, until you get to this `Paks` folder here
<br />`EscapeTheBackrooms&#92;EscapeTheBackrooms&#92;Content&#92;Paks`
<br />
<br />Then once you get here, create an `interpose_mods` folder and place the `Z_Interpose_P.pak` here so it looks like
<br />`EscapeTheBackrooms&#92;EscapeTheBackrooms&#92;Content&#92;Paks&#92;interpose_mods&#92;Z_Interpose_P.pak`
<br />
<br />Now when you open the game you can use the following keys to access the mod loader!
<br />
<br />Keys:
<br />`F1`: Toggle Mod Loader Menu (Must be loaded in a level, not at the main menu)
<br />`Escape`: Fast Quit
